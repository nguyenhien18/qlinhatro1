# Rental Management System

## Overview
The Rental Management System is designed to streamline the process of managing rental properties, including tracking rental agreements, tenant information, and payment history. This system aims to enhance the efficiency of property management operations, providing a user-friendly interface for both property managers and tenants.

## Features
- **Property Management**: Ability to add, update, and remove properties in the system.
- **Tenant Information**: Maintain detailed records of tenants, including personal information and rental history.
- **Payment Tracking**: Monitor rent payments, due dates, and payment history.
- **Reporting**: Generate reports on rental income, expenses, and occupancy rates.
- **User Authentication**: Secure login for property managers and tenants.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/nguyenhien18/qlinhatro1.git
   ```
2. Navigate to the project directory and install dependencies:
   ```bash
   cd qlinhatro1
   npm install
   ```

## Usage
- Start the development server:
   ```bash
   npm start
   ```
- Access the application at `http://localhost:3000`.
